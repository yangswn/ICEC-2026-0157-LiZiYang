## 三、我从数据里看出的四条结论

### 结论一：信号强度够强时，延迟"锁死"在 43–47 ms；跌破 −100 dBm 才开始失控

| 点位 | 平均 RSRP | 3 次延迟 |
|---|---|---|
| P02 | −60 | 43.0 / 43.0 / 47.0 |
| P05 | −73 | 42.0 / 43.0 / 46.0 |
| P06 | −84 | 43.0 / 44.0 / 45.0 |
| P01 | −85 | 44.0 / 46.0 / 46.0 |
| P07 | −95 | 43.0 / 43.0 / 45.0 |
| P03 | −91 | 43.0 / 43.0 / 46.0 |
| **P04** | **−105** | **48.0 / 53.0 / 45.0** |
| **P08** | **−107** | **65.0 / 75.0 / 298** |

**信号从 −60 到 −96 dBm（跨度 36 dB、约 4000 倍功率差），六个点位的延迟全部落在 42–47 ms 之间。**

而且这个规律**跨制式也成立**：P02 是 4G，延迟照样是 43–47 ms。

**跌出去的两个点位（P04、P08）有一个共同点：RSRP 都 ≤ −100 dBm。**

**我的理解**：延迟反映的是"链路是否顺畅"（排队、重传）。只要信号强到一定程度，链路就稳定；一旦弱到某条线以下，重传和排队就开始出现，延迟随之失控。**约 −100 dBm 是我在本次数据里看到的这条线。**

### 结论二：信号强度不能用来预测网速

这一条我手上有两组证据，一正一反：

**（a）反向证据 —— 信号更差，网速反而更快**

| P06 教学楼大道 | RSRP | 下载 |
|---|---|---|
| 10-15 18:48 | **−74** | **10.7** |
| 10-16 19:09 | **−83 / −85** | **58.6 / 80.8** |

同一个位置、同样都是傍晚、只隔一天：**信号掉了 9 dB，网速快了 5–7 倍。**

**（b）最极端的一组 —— 信号完全相同，网速差 20 倍以上**

| 点位 | RSRP | 下载 |
|---|---|---|
| **P04 楼梯间** | **−104 / −109** | **42.2 / 51.3** |
| **P08 宿舍** | **−104 / −109** | **0.94 / 2.86 / 0.55** |

**两个点位的信号强度完全同级，下载速度差了 20 倍以上。**

**我的理解**：RSRP 只说明"信号有多强"，不说明"基站愿意分给你多少带宽"。后者取决于小区负载、调度、回传带宽等因素，这些都不反映在 RSRP 上。

> ⚠️ **这一条我必须说明局限**：P04 是 10-16 傍晚测的，P08 是 10-15 深夜测的，**两次不是同一时刻**。所以严谨的说法是"该现象提示……"，而不是"证明……"。

### 结论三：4G 跑赢了 5G

P02 是我 8 个点位中**唯一回落到 4G** 的（其余全部是 5G n78）：

| 点位 | 制式 | 带宽 | RSRP | 下载 |
|---|---|---|---|---|
| **P02** | **4G B1** | **20 MHz** | −60 | 50.6 / 61.0 |
| **P02** | **4G B3**（10-15） | **20 MHz** | −74 | **73.1** |
| P03 | 5G n78 | 100 MHz | −93 | 17.8 / 20.8 |
| P01 | 5G n78 | 100 MHz | −86 | 17.6 / 21.3 |

**带宽只有 20 MHz 的 4G，下载速度超过了带宽 100 MHz 的 5G。** 而且**两次测量（B1、B3 两个不同频段）都复现了这个结果**。

**我的推测**（这一条是推测，不是结论）：P02 位于 L 型转角，主瓣方向被墙体遮挡。5G 用的 n78 是 3.5 GHz 左右的高频，**穿墙和绕射能力差**；4G 的 B1/B3 在 1.8–2.1 GHz，**传播条件更好**。所以手机在这里直接放弃了 5G，回落到 4G —— **而 4G 反而给出了更好的速率**。

### 结论四：单次测速完全不可靠，重复测量离散度很大

**这是我认为本次采样最有价值的一条。**

我手里有三组"同一点位、短时间内连测"的数据：

| 点位 | 下载（3 次） | 最大/最小 | 抖动（3 次） | 最大/最小 |
|---|---|---|---|---|
| **P08 宿舍** | 0.94 / 2.86 / 0.55 | **5.2 倍** | 15.7 / 475 / 298 | **30 倍** |
| **P04 楼梯间** | 12.8 / 42.2 / 51.3 | **4.0 倍** | 11.3 / 13.4 / 3.95 | 3.4 倍 |
| **P07 办公室走廊** | 18.6 / 16.3 / 16.3 | 1.14 倍 | 9.29 / 254 / 89.7 | **27 倍** |

**同一个位置、没有移动、相隔只有 1–2 分钟，下载速度能差 4–5 倍，抖动能差 30 倍。**

→ 这说明：**单次测量得到的网速，几乎不能代表这个点位的真实水平。**
→ 这也印证了采样规范里"每点位连续测 3 次"是**必需的，不是多余的规定**。
→ 我在报告里会据此说明：**任何单次读数都应视为一个样本，而不是该点位的"速度"。**

## 四、这份数据有哪些局限（我自己先说清楚）

我把这份数据的问题都列出来，避免被误读：

1. **各点位的测量时段不统一。** P07/P03/P01/P05 是 10-16 上午测的，P06/P04/P02 是 10-16 傍晚测的，P08 是 10-15 深夜。**时段差异会影响基站负载，因此不同点位之间的横向对比要谨慎**，"谁比谁快"的结论强度有限。
2. **P04 与 P08 的对比不是同一时刻。** 结论二里那组"信号相同、网速差 20 倍"的数据，两点位测量时间相隔约 20 小时，**不能作为严格的对照实验**，只能作为现象提示。
3. **RSRP / SNR 来自手机场测模式，不是专业仪表。** 手机和标准测量设备之间有差距，读数只适合**横向对比**，不适合当绝对真值引用。
4. **部分点位的场测截图只有 2 张**（P01/P03/P05/P06/P07/P04/P02 都是"2 张场测 + 2~3 张测速"），**信号值与测速值的对应关系是按截图顺序配对的**，可能与实际顺序有出入。
5. **P06 的场地照是白天拍摄，数据是当晚测量。** 当时时间紧张，照片与数据不同时。场地照仅用于记录环境，不涉及"本人到场"的证明（那是同框照的作用）。
6. **P02 的 RSRP（−60 dBm）是 4G 的读数**，与其余点位 5G 的 RSRP **不同制式、不同频段，不可直接比较数值**。
