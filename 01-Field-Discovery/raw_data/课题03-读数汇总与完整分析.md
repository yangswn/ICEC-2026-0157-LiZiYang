## 三、我从数据里看出的四条结论

### 结论一：信号强度够强时，延迟"锁死"在 43–47 ms；跌破 −100 dBm 才开始失控

| 点位 | 平均 RSRP | 3 次延迟 |
|---|---|---|
| P02 | −60 | 43.0 / 43.0 / 47.0 |
| P05 | −73 | 42.0 / 43.0 / 46.0 |
| P06 | −84 | 43.0 / 44.0 / 45.0 |
| P01 | −85 | 44.0 / 46.0 / 46.0 |
| P07 | −95 | 43.0 / 43.0 / 45.0 |
| P03 | −91 | 43.0 / 43.0 / 46.0 |
| **P04** | **−105** | **48.0 / 53.0 / 45.0** |
| **P08** | **−107** | **65.0 / 75.0 / 298** |

**信号从 −60 到 −96 dBm（跨度 36 dB、约 4000 倍功率差），六个点位的延迟全部落在 42–47 ms 之间。**

而且这个规律**跨制式也成立**：P02 是 4G，延迟照样是 43–47 ms。

**跌出去的两个点位（P04、P08）有一个共同点：RSRP 都 ≤ −100 dBm。**

**我的理解**：延迟反映的是"链路是否顺畅"（排队、重传）。只要信号强到一定程度，链路就稳定；一旦弱到某条线以下，重传和排队就开始出现，延迟随之失控。**约 −100 dBm 是我在本次数据里看到的这条线。**

### 结论二：信号强度不能用来预测网速

这一条我手上有两组证据，一正一反：

**（a）反向证据 —— 信号更差，网速反而更快**

| P06 教学楼大道 | RSRP | 下载 |
|---|---|---|
| 10-15 18:48 | **−74** | **10.7** |
| 10-16 19:09 | **−83 / −85** | **58.6 / 80.8** |

同一个位置、同样都是傍晚、只隔一天：**信号掉了 9 dB，网速快了 5–7 倍。**

**（b）最极端的一组 —— 信号完全相同，网速差 20 倍以上**

| 点位 | RSRP | 下载 |
|---|---|---|
| **P04 楼梯间** | **−104 / −109** | **42.2 / 51.3** |
| **P08 宿舍** | **−104 / −109** | **0.94 / 2.86 / 0.55** |

**两个点位的信号强度完全同级，下载速度差了 20 倍以上。**

**我的理解**：RSRP 只说明"信号有多强"，不说明"基站愿意分给你多少带宽"。后者取决于小区负载、调度、回传带宽等因素，这些都不反映在 RSRP 上。

> ⚠️ **这一条我必须说明局限**：P04 是 10-16 傍晚测的，P08 是 10-15 深夜测的，**两次不是同一时刻**。所以严谨的说法是"该现象提示……"，而不是"证明……"。

### 结论三：4G 跑赢了 5G

P02 是我 8 个点位中**唯一回落到 4G** 的（其余全部是 5G n78）：

| 点位 | 制式 | 带宽 | RSRP | 下载 |
|---|---|---|---|---|
| **P02** | **4G B1** | **20 MHz** | −60 | 50.6 / 61.0 |
| **P02** | **4G B3**（10-15） | **20 MHz** | −74 | **73.1** |
| P03 | 5G n78 | 100 MHz | −93 | 17.8 / 20.8 |
| P01 | 5G n78 | 100 MHz | −86 | 17.6 / 21.3 |

**带宽只有 20 MHz 的 4G，下载速度超过了带宽 100 MHz 的 5G。** 而且**两次测量（B1、B3 两个不同频段）都复现了这个结果**。

**我的推测**（这一条是推测，不是结论）：P02 位于 L 型转角，主瓣方向被墙体遮挡。5G 用的 n78 是 3.5 GHz 左右的高频，**穿墙和绕射能力差**；4G 的 B1/B3 在 1.8–2.1 GHz，**传播条件更好**。所以手机在这里直接放弃了 5G，回落到 4G —— **而 4G 反而给出了更好的速率**。

### 结论四：单次测速完全不可靠，重复测量离散度很大

**这是我认为本次采样最有价值的一条。**

我手里有三组"同一点位、短时间内连测"的数据：

| 点位 | 下载（3 次） | 最大/最小 | 抖动（3 次） | 最大/最小 |
|---|---|---|---|---|
| **P08 宿舍** | 0.94 / 2.86 / 0.55 | **5.2 倍** | 15.7 / 475 / 298 | **30 倍** |
| **P04 楼梯间** | 12.8 / 42.2 / 51.3 | **4.0 倍** | 11.3 / 13.4 / 3.95 | 3.4 倍 |
| **P07 办公室走廊** | 18.6 / 16.3 / 16.3 | 1.14 倍 | 9.29 / 254 / 89.7 | **27 倍** |

**同一个位置、没有移动、相隔只有 1–2 分钟，下载速度能差 4–5 倍，抖动能差 30 倍。**

→ 这说明：**单次测量得到的网速，几乎不能代表这个点位的真实水平。**
→ 这也印证了采样规范里"每点位连续测 3 次"是**必需的，不是多余的规定**。
→ 我在报告里会据此说明：**任何单次读数都应视为一个样本，而不是该点位的"速度"。**

## 四、墙体材质与多径衰减

这一节回答的问题是：**同样在教学楼里走，为什么有的地方信号掉、有的地方信号没掉多少但网速很差？**

### 4.1 先把两种"衰减"分开

我一开始把它们混在一起，越看越乱。分开之后才清楚：

| | 穿透损耗 | 多径干涉 |
|---|---|---|
| **发生什么** | 墙把电磁波吸收了、挡掉了，到达手机的能量变少 | 信号沿好几条路径先后到达，相位不同、互相抵消 |
| **数据上表现为** | **RSRP 掉** | **SNR 掉**，而 RSRP 可能还不错 |
| **典型地点** | 实心墙、楼板、室内深处 | 金属井道、金属扶手、装了大量管线的封闭空间 |
| **怎么改善** | 加中继、靠近窗口、换低频段 | 换频段、调整天线方向、用分集接收 |

**这张表是这一节的地基。** 后面所有分析都建立在"这是两种不同的病"这个判断上。

### 4.2 用 SNR 当"多径乱不乱"的尺子

RSRP 只告诉我"信号有多强"，**SNR（信噪比）才告诉我"这份信号有多干净"** —— 多径一严重，接收端分不清谁是主信号，SNR 就掉下来。

8 个点位按 SNR 中位数排序【全部为实测读数，来自 `raw_data/`】：

| 排序 | 点位 | 空间类型 | RSRP 三次（dBm） | SNR 三次 | **SNR 中位** |
|---|---|---|---|---|---|
| 1 | P02 L型转角 | 拐角 | −74 / −60 / −60 | 27.0 / 30.0 / 30.0 | **30.0** |
| 2 | P05 靠窗开阔 | 窗边 | −71 / −73 / −73 | 28.5 / 26.5 / 26.5 | **26.5** |
| 3 | P01 长直走廊 | 走廊 | −84 / −85 / −87 | 22.6 / 26.6 / 25.5 | **25.5** |
| 4 | P07 办公室门口走廊 | 走廊 | −99 / −94 / −91 | 18.3 / 18.5 / 6.8 | **18.3** |
| 5 | P06 教学楼大道 | 室外道路 | −74 / −83 / −85 | 22.3 / 11.8 / 11.5 | **11.8** |
| 6 | P08 宿舍 | 室内 | −109 / −104 / −109 | 10.5 / 8.0 / 9.5 | **9.5** |
| 7 | P04 楼梯间 | 楼梯 | −103 / −104 / −109 | 11.0 / 7.8 / 4.0 | **7.8** |
| 8 | P03 电梯口 | 电梯厅 | −86 / −96 / −91 | 19.5 / 1.5 / 5.6 | **5.6** |

### 4.3 三个反直觉的对照组（这节的核心）

**① P03 电梯口 vs P04 楼梯间 —— 信号更强的地方，信噪比反而更差**

| | RSRP 中位 | SNR 中位 |
|---|---|---|
| P03 电梯口 | **−91 dBm** | **5.6** |
| P04 楼梯间 | **−104 dBm** | **7.8** |

**电梯口的信号比楼梯间强 13 dB —— 功率约 20 倍，可它的 SNR 却低了 2.2 dB。**

这一组把我原来"信号弱所以网差"的直觉直接推翻了。它说明的是：

- **P04 楼梯间是"穿透损耗"型的病**：上下贯通，混凝土楼板 + 不锈钢扶手一路挡，能量真的被吃掉，所以 RSRP 跌到 −104；但主径还算清楚，SNR 没崩到最差。
- **P03 电梯口是"多径干涉"型的病**：电梯井是金属井道，3.5 GHz 在里面反复反射，好几路信号几乎同时到达手机，**能量不缺，缺的是"哪一份是主信号"** —— 所以 RSRP 还有 −91，SNR 只有 5.6。

**同样是"电梯口/楼梯间信号差"，病因不一样，解决办法也不一样。** 这一条是我这次最想写进报告的判断。

**② P05 靠窗 vs P01 长直走廊 —— 信号差 12 dB，信噪比几乎一样**

| | RSRP 中位 | SNR 中位 |
|---|---|---|
| P05 靠窗开阔 | −73 dBm | 26.5 |
| P01 长直走廊 | −85 dBm | 25.5 |

靠窗那边信号强 12 dB（约 16 倍功率），但两处的 SNR **只差 1 dB**。

→ 再次说明 **RSRP 和 SNR 是两个独立变化的东西**，不能互相顶替。
→ 【我的推断】P01 是笔直走廊、两侧实体墙 + 玻璃隔断，主径短而直接，**走廊结构反而抑制了多径**，所以即使信号弱一些，信道照样干净。

**③ P06 室外开阔，SNR 却比室内走廊还低**

| | 空间 | SNR 中位 |
|---|---|---|
| P01 长直走廊 | 室内 | **25.5** |
| P06 教学楼大道 | **室外无遮挡** | **11.8** |

**"没有墙挡着"≠"信噪比好"。**

【我的推断】原因大概有两层：室外基站离得远（距离衰减），而且室外能收到更多邻区信号（同频干扰），这两样都会压低 SNR。**开阔只解决"遮挡"，不解决"距离"和"干扰"。**

### 4.4 把材质/结构对上去

下面这张表里，**「现场观察」是实测记录，「推断机制」是我的判断**：

| 点位 | 现场观察（实测描述） | 推断的主导机制 | 数据支持 |
|---|---|---|---|
| P03 电梯口 | 电梯井为**金属结构**，强反射环境 | **多径干涉**为主 | SNR 中位仅 5.6，**全场最差** |
| P04 楼梯间 | 上下楼层**贯通**，反射路径复杂 | **穿透损耗**为主 | RSRP 中位 −104，**全场倒数第二** |
| P08 宿舍 | 室内房间，**建筑墙体**遮挡严重 | 穿透损耗 + 距离 | RSRP −109，全场最弱 |
| P01 长直走廊 | 两侧**实体墙 + 玻璃隔断**，直通道 | 两者都较轻（主径清晰） | SNR 25.5，排第 3 |
| P07 办公室走廊 | 走廊**尽头**，两侧多个房间门 | 穿透（门开闭影响大） | RSRP −94，SNR 波动大（18.3→6.8）|
| P05 靠窗 | 靠窗、**遮挡最少**，接近视距 | 基本只有**自由空间损耗** | RSRP −73（室内最强），SNR 26.5 |
| P06 室外 | **无建筑遮挡** | 距离衰减 + 邻区干扰 | SNR 仅 11.8，反低于室内 |
| P02 L型转角 | 拐角，**主瓣方向被墙体遮挡** | 见 4.5（频段因素） | RSRP −60，SNR 30.0（最好）|

### 4.5 还有一个混进来的变量：频段

**P02 是这批里唯一回落到 4G 的点位**（10-15 测到 LTE B3，10-16 测到 LTE B1），其余 7 个点位都是 **5G n78**。

粗略地讲，B1/B3 在 1.8–2.1 GHz 一带，n78 在 3.5 GHz 一带 —— **频率越低，穿透和绕射能力越好**。

【我的推断】P02 在 L 型转角、主瓣被墙挡住，5G 的 3.5 GHz 拐不过弯，手机干脆回落到 4G；而 4G 的波长更长，**沿着转角绕过去的能力更强**，所以反而拿到了 SNR 30.0 —— 全批最好。

⚠️ **但这条要打折扣**：
- **P02 的 RSRP（−60 dBm）是 4G 读数，跟其余点位的 5G 读数不是同一个口径，不能直接比数值。**
- 我没有做"同一点位、切换频段"的对照实验，所以只能说"**现象与频段特性相符**"，不能说"**已证明是频段导致的**"。

### 4.6 这一节做不到的地方（先说清楚）

1. **材质是目视判断，没有参数。** 我记录了"实体墙""玻璃隔断""金属井道""楼层贯通"，但**没有测墙体厚度、没有测材料的渗透损耗**。4.4 表里"推断机制"那一列，性质是**基于物理常识的推测，不是实测结论**。
2. **没有对照实验。** 要严格证明材质或频段的影响，应该在**同一个位置**改变单一变量（换频段、开门/关门、贴墙/离墙 1 米）再测。这次是"换位置"，一变全变，**严格说只能得到相关性**。
3. **SNR 自身波动很大。** 最典型的是 P03：三次是 **19.5 / 1.5 / 5.6**，同一点位、相隔几分钟，差 18 dB。所以我在 4.2 和 4.3 里统一用了**中位数**，而不是随便挑一次。
4. **P07 出现了反常组合**：信号从 −99 升到 −91（变强），SNR 却从 18.3 掉到 6.8（变差）。这说明**在我没控制住的变量里（邻区负载、瞬时干扰、人来人往），还有比信号强度影响更大的东西**。这条我写进报告，作为"单次测量不可靠"的又一个证据。

| 要验证什么 | 怎么做 |

| 金属井道导致多径 | 在电梯口**正对电梯门 / 侧身 90° / 退后 2 米**各测 3 次，看 SNR 是否随朝向变化 |

## 五、这份数据有哪些局限（我自己先说清楚）

我把这份数据的问题都列出来，避免被误读：

1. **各点位的测量时段不统一。** P07/P03/P01/P05 是 10-16 上午测的，P06/P04/P02 是 10-16 傍晚测的，P08 是 10-15 深夜。**时段差异会影响基站负载，因此不同点位之间的横向对比要谨慎**，"谁比谁快"的结论强度有限。
2. **P04 与 P08 的对比不是同一时刻。** 结论二里那组"信号相同、网速差 20 倍"的数据，两点位测量时间相隔约 20 小时，**不能作为严格的对照实验**，只能作为现象提示。
3. **RSRP / SNR 来自手机场测模式，不是专业仪表。** 手机和标准测量设备之间有差距，读数只适合**横向对比**，不适合当绝对真值引用。
4. **部分点位的场测截图只有 2 张**（P01/P03/P05/P06/P07/P04/P02 都是"2 张场测 + 2~3 张测速"），**信号值与测速值的对应关系是按截图顺序配对的**，可能与实际顺序有出入。
5. **P06 的场地照是白天拍摄，数据是当晚测量。** 当时时间紧张，照片与数据不同时。场地照仅用于记录环境，不涉及"本人到场"的证明（那是同框照的作用）。
6. **P02 的 RSRP（−60 dBm）是 4G 的读数**，与其余点位 5G 的 RSRP **不同制式、不同频段，不可直接比较数值**。
