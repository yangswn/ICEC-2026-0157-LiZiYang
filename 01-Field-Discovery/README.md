## 三、我自己加的两个校验

原文没要求，但我做完数据后自己跑了一遍，防止「表格填满了但数是错的」：

- **`check_data.py`**：检查每张表有没有空行、组数对不对、取值有没有超出合理范围；
- **`verify_noise.py`**：用同一组数据的 L10 / L50 / L90 反算 Leq，和 NoiseLedger 给的数对比。

## 四、我在文档里写明的局限

- 手机和手表**都不是标准声级计**，读数只能横向对比，不能当绝对声压级；
- 测速延迟里包含了一部分城际链路，不完全是校园网内延迟；
- `Leq` 依赖 App 内部算法，**无法从 L10/L50/L90 独立完整复算**，只能近似核对。

这三条我都写进了对应分析文档，没有藏起来。
