## 一、我的文件命名规则【我的安排】

我统一用这个格式，这样在文件管理器里排序时，**同一个点位的内容会挨在一起**：

```
T<课题号>_P<点位号>_<时段>_<类型>_<日期-时间>.jpg
```

| 字段 | 我填什么 | 说明 |
|---|---|---|
| 课题号 | `T03` / `T06` | T03 = 无线信号，T06 = 噪声 |
| 点位号 | `P01` ~ `P08` | 课题 03 用到 P01–P08；课题 06 用到 P01–P05 |
| 时段 | `早` / `午` / `晚` | **只有课题 06 要加这一节** |
| 类型 | `点位照` / `同框照` | 见下一条 |
| 日期-时间 | `20261015-0830` | 年月日-时分，24 小时制 |

**我的示例：**

```
T03_P01_点位照_20261015-0830.jpg      ← 拍这个位置长什么样
T03_P01_同框照_20261015-0830.jpg      ← 我本人在现场（这是关键证据）
T06_P03_午_点位照_20261015-1230.jpg
T06_P03_午_同框照_20261015-1230.jpg
T06_P03_午_实测截图_20261015-1232.jpg ← 手机屏幕的读数也存一张，防争议
```

## 二、我拍两类照片

### `点位照` —— 拍环境

拍出这个点位的**空间特征**：走廊有多长、转角是什么角度、有没有实心墙、电梯口朝向哪。
**不用拍人。**

### `同框照` —— 拍我自己

**【原文】** 第一阶段统一要求："本人现场同框照片"

**我拍的时候要保证画面里能同时看出这三件事：**

1. ✅ **我本人**（脸要能认出来，不能只拍手）
2. ✅ **现场环境**（从背景能看出是哪个点位）
3. ✅ **正在测量**（手机屏幕上的测速或分贝读数）

**我的拍法**：用手机定时器自拍，或者请同学帮我拍。
举着手机拍屏幕是有点傻，但这是要求 —— **面试时要靠它证明我是亲自去的。**

## 三、课题 03 我要怎么采（8 点位 × 3 次 = 24 组）

### 第 1 步 · 选 8 个点位（遮挡特征要各不相同）【我的安排】

| 编号 | 我打算选 | 为什么选这种 |
|---|---|---|
| P01 | 长直走廊（两侧实心墙） | 典型弱信号场景 |
| P02 | L 型转角 | 测多径反射 |
| P03 | 电梯口 | 金属结构遮挡 |
| P04 | 楼梯间 | 多层结构叠加 |
| P05 | 靠窗开阔位置 | 对照组（信号应该好） |
| P06 | 室内房间中央 | 和走廊对比 |
| P07 | 建筑中庭 | 开阔但有顶 |
| P08 | 宿舍走廊 | 题目点名了宿舍 |

### 第 2 步 · 到点位之后

1. 先拍 `点位照`
2. 再拍 `同框照`
3. 打开测速 APP，连续测 **3 次**（每次间隔 1–2 分钟，不要连着点）

### 第 3 步 · 当场记录

信号强度、下载速度、上传速度、延迟 —— **当场填进 CSV**。

> ⚠️ **我不攒着回家再填。** 现场记错一个数字，回家就想不起来了。

## 五、我填数据时要注意的

### ✅ CSV 已经加了 UTF-8 BOM

可以**直接双击用 Excel 或 WPS 打开，中文不会乱码**。

### ⚠️ 我的三条禁忌

1. **不改表头** —— 第三阶段面试会调取我的原始数据核对，表头被改过会显得可疑
2. **不删列** —— 没数据就留空，不删
3. **不手动排序** —— 按 `序号` 顺序填就行

### 💡 万一 Excel 里中文还是乱码

用 **WPS 或 Excel 的「数据 → 从文本/CSV 导入」**，编码选 **UTF-8**。
