## 一、文件命名规则【建议】

统一用这个格式，**保证按文件管理器排序时同点位的内容挨在一起**：

```
T<课题号>_P<点位号>_<时段>_<类型>_<日期-时间>.jpg
```

| 字段 | 取值 | 说明 |
|---|---|---|
| 课题号 | `T03` / `T06` | T03 = 无线信号，T06 = 噪声 |
| 点位号 | `P01` ~ `P08` | 课题 03 用到 P01–P08；课题 06 用到 P01–P05 |
| 时段 | `早` / `午` / `晚` | **只有课题 06 需要**，课题 03 不加这一节 |
| 类型 | `点位照` / `同框照` | 见下方说明 |
| 日期-时间 | `20261015-0830` | 年月日-时分，24 小时制 |

**示例：**

```
T03_P01_点位照_20261015-0830.jpg      ← 拍这个位置长什么样
T03_P01_同框照_20261015-0830.jpg      ← 你本人在现场（关键证据）
T06_P03_午_点位照_20261015-1230.jpg
T06_P03_午_同框照_20261015-1230.jpg
T06_P03_午_实测截图_20261015-1232.jpg ← 手机屏幕读数也存一张，防争议
```

## 二、照片要求

### `点位照` —— 拍环境
拍出这个点位的**空间特征**：走廊有多长、转角是什么角度、有没有实心墙、电梯口朝向哪。**不用拍人。**

### `同框照` —— 拍你自己【原文要求】
**【原文】** 第一阶段统一要求：*"本人现场同框照片"*

**一张合格的"同框照"要同时能看出这三件事：**

1. ✅ **你本人**（脸要能认出来，别只拍手）
2. ✅ **现场环境**（背景能看出是在哪个点位）
3. ✅ **正在测量**（手机屏幕上的测速/分贝读数，或者你的记录本）

**怎么拍**【建议】：用手机定时器自拍，或者请同学帮拍。举着手机拍屏幕是会有点傻，但这是要求 —— **面试时要靠它证明你是亲自去的**。

## 三、课题 03 采集步骤（8 点位 × 3 次 = 24 组）

**第 1 步 · 选点位**（8 个，遮挡特征要各不相同）【建议】

| 编号 | 建议类型 | 为什么要这种 |
|---|---|---|
| P01 | 长直走廊（两侧实心墙） | 典型弱信号场景 |
| P02 | L 型转角 | 测多径反射 |
| P03 | 电梯口 | 金属结构遮挡 |
| P04 | 楼梯间 | 多层结构叠加 |
| P05 | 靠窗开阔位置 | 对照组（信号应该好） |
| P06 | 室内房间中央 | 与走廊对比 |
| P07 | 建筑中庭 | 开阔但有顶 |
| P08 | 宿舍走廊 | 题目点名了宿舍 |

**第 2 步 · 到点位后**
1. 先拍 `点位照`
2. 再拍 `同框照`
3. 打开测速 APP，连续测 **3 次**（每次间隔 1–2 分钟，别连点）

**第 3 步 · 记录** 信号强度、下载速度、上传速度、延迟 → **当场填进 CSV**

> ⚠️ **别攒着回家再填。** 现场记错一个数字，回家就想不起来了。

## 四、课题 06 采集步骤（5 点位 × 3 时段 = 15 组）

**第 1 步 · 选点位**（题目点名了 5 类）【原文】
> 图书馆、食堂、主干道、运动场、实训室走廊

**第 2 步 · 三个时段各跑一遍**

⚠️ **【未核实】** 原文只写了"早/午/晚"，**没定义具体时间**。我的建议：

| 时段 | 建议时间 | 理由 |
|---|---|---|
| 早 | 07:00 – 09:00 | 上课人流 |
| 午 | 11:30 – 13:30 | 午休高峰 |
| 晚 | 20:00 – 22:00 | 夜自习 |

**→ 10/21 答疑时务必确认时段的准确定义。** 在那之前，你**把每次的准确时间记在 CSV 的"时间"列里**，这样无论老师怎么定义，你的数据都能对上。

**第 3 步 · 每个点位测 3–5 分钟**，记录：
- 平均声压级（dBA）
- 最高 / 最低声压级
- 主要噪声源（人声 / 交通 / 设备 / 音乐）

**第 4 步 · 拍照**：`点位照` + `同框照`

## 五、填数据时的注意事项

### ✅ CSV 已经加了 UTF-8 BOM
可以**直接双击用 Excel 或 WPS 打开，中文不会乱码**。这是提前处理好的。

### ⚠️ 三条禁忌
1. **不要改动表头** —— 第三阶段面试会调取你的原始数据核对，表头被改过会显得可疑
2. **不要删列** —— 没数据就留空，别删
3. **不要手动排序** —— 按 `序号` 顺序填就行

### 💡 如果 Excel 里中文还是乱码
用 **WPS 或 Excel 的「数据 → 从文本/CSV 导入」**，编码选 **UTF-8**，就正常了。
