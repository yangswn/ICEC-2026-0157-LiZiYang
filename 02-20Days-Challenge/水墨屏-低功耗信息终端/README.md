> 这是我给 ICEC 第二阶段申报的**自选项目**。老师说明会上提到「项目可以自己选择、可以创新，也推荐创新制作」。
> 记录原则：**做成的和没做成的都写**，尤其是失败和返工——它们才是过程证据。

## 一句话定位

用一块拆机四色电子纸 + 自制充电板，做一个**每天刷新一次、一次充电能撑数周**的桌面信息终端。

不是电子相框，**核心指标是续航和刷新可靠性，不是画质**。

## 三个要写进报告的技术判断

**① 电池不能直接给主控供电**
电池满电 4.2V，nRF52811 的 VDD 上限约 3.6V → 必须经 LDO 降到 3.0V。这就是 `ME6210A30PG` 的作用。选 SOT-89 封装而非 SOT-23，因为同型号不同封装引脚间距完全不同。

**② 为什么用 J-Flash Lite 而不是教程里的 J-Flash**
SEGGER 官方手册写明 J-Flash 需 license，连正版 J-Link BASE 都不含该授权，克隆的 J-Link OB 必然报 `no valid license`；J-Flash Lite 免费且在同安装包内，烧内部 flash 够用。

**③ 为什么用拆机屏**
新屏模块数百元，拆机件二手 10–30 元且规格更高。代价是**要自己解决驱动板、FPC 转接和固件**——这正是本项目的主要工作量。
