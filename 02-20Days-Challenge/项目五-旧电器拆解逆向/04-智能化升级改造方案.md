# 项目五 ④ · 旧电器智能化升级改造方案

> 对象：透明充电式手持小风扇（PCB 丝印 `Y30` / `20260202`）
> 基线确认：拆解后已复原装配，**通电仍能正常运转**（2026-11-07 确认）
> 对应原文要求：含原板取电与控制接入点标注图、20 元内增量器件选型表及控制状态图，**动手完成接线验证直接满分**

---

## 0. 一句话目标

让这台风扇**不用按按钮，温度高了自己开、凉下来自己停**，且**保留原来手动按也能开**的能力。

---

## 1. 改造前后的差别

| | 改造前 | 改造后 |
|---|---|---|
| 谁决定开不开 | **人按按钮** | **温度自己判断**（按键仍需按一次唤醒） |
| 电路路径 | 电池 → U1/U4 → Q1 → **M+ → 电机** | 电池 → U1/U4 → Q1 → **M+ → 继电器 → 电机** |
| 需要人管吗 | 一直在管 | **开起来之后不用管** |

**关键点：不是把原电路"改掉"，而是"在 M+ 这根线上插一个开关进去"。**
原芯片一个脚都不用碰，改造失败把线接回原位就恢复。

## 3. ⚠️ 最大的坑：这个模块从哪儿取电

我对着你 README 里记的硬件信息算了一遍：

| 事实 | 来源 | 推论 |
|---|---|---|
| 电池是 2 节 18650 **并联**，3.7V | 你的 README | 电池侧只有 **3.7V** |
| 板上**无电感**，非升降压拓扑 | 你的 README | U3 是线性充电管理，**不会升压** |
| Type-C 输入 5V | 你的 README | 但**只有插着线时才有 5V** |

**所以：**

- 想做成「插着 Type-C 才工作」→ 取 5V，选 5V 模块，最容易，但失去便携
- 想做成「不插线也能自动开」→ 必须选**能在 3.7V 工作的宽压模块**

**买之前一定要问卖家一句：「供电电压 3.7V 能用吗？」**
市面上大量温控模块是 12V 供电的，买回来接 3.7V 根本不启动，那 20 块钱和时间就白花了。

## 4. 取电点与控制接入点（对应原文要求的标注图）

板子底部有两组绿色接线端子，加上左下角的 `B−` 圆孔，正好是下面这几个点（位置已用原图放大 4 倍核对）：

| 点 | 位置（对照实物照片） | 这次怎么用 |
|---|---|---|
| **B+** | 底部**左侧**那组端子的**右位** | **给温控模块供电（正）** |
| **B−** | 底部左侧那组端子的**左位**（左边另有 `B−` 丝印与 J1 圆孔） | **给温控模块供电（负）** |
| **M+** | 底部**右侧**那组端子的**左位** | **断开它，把继电器串进去** |
| **M−** | 底部右侧那组端子的**右位**（旁有 `M1` 丝印） | **不动，保持原样** |

> ⚠️ 照片上丝印的位置和端子的对应关系只能算"高置信推断"，**接之前务必用万用表核实**：
> 电池接好后，直流电压档量 B+ 与 B− 之间应读到 **3.5~3.9V**；
> M+ 与 M− 之间在不按按钮时应接近 **0V**。量对了再接。

### 为什么选「串在 M+ 上」

原电路是：`M+ 端子 → 电机正极`。
把这一根线断成两段，中间插入继电器：`M+ 端子 → COM ……… NO → 电机正极`。

**好处：**
- 只碰一个端子、一根线，不动任何芯片引脚
- 不用拆焊、不用认 MOS 管脚位（对新手最要紧）
- 完全可逆：把线拧回原位就恢复出厂状态

**代价（这条必须写进报告，别隐瞒）：**
- 原机是轻触按键，要先按一下让 U3 唤醒，之后才由温度接管通断
- 也就是说：**开机仍需手动一次，但运行过程全自动**

> 所以严谨的说法是「**半自动温控**」，不是「完全不用管」。报告里按前者写。

### 备选（想让开机也自动才用）

把继电器触点**并联在 Q1（Si2302，SOT-23）的漏极与源极之间**，就能做到"手动或自动"完全并行。
但需要：先在板上找到 Q1 并确认丝印 `A2SHB` → 万用表确认哪脚通 GND（源极）、哪脚通 M−（漏极）→ 在 SOT-23 这么小的封装上动烙铁。

【Q1 位置已确认（2026-11-08 原图放大后看清）】
Q1 在 **D1 的正上方、C8 的右下方、R5 的左侧**，是一只 SOT-23 小三脚器件，丝印 `Q1` 竖排在它左下。

若要做并联，接线前必须先用万用表通断档确认：
- 哪只脚 **通 GND** → 源极（S）
- 哪只脚 **通 M−** → 漏极（D）

⚠️ **千万不要接到栅极**——那是 U3 输出的控制信号线，接上去等于把 U3 的输出短路到电源，会烧芯片。栅极的特征是：它既不与 GND 通，也不与 M− 通，只与 U3 的一个引脚相连。

**但即使找到了 Q1，我的建议仍是先走"串联 M+"**：拧两个端子螺丝 vs 在 0.95mm 间距的 SOT-23 上焊两根线，后者对新手风险高得多（容易连锡或烫掉焊盘）。

## 5. 控制状态图

```
        ┌──────────────────────────────┐
        │  待机（继电器断开，电机不转）    │
        └──────────────┬───────────────┘
                       │
        温度 ≥ 设定值（如 32°C）
                       ↓
        ┌──────────────────────────────┐
        │  运转（继电器吸合，电机通电）    │
        └──────────────┬───────────────┘
                       │
        温度 ≤ 设定值 − 回差（如 30°C）
                       ↓
                   回到待机
```

**回差（Hysteresis）为什么必须设：**
如果只有一条线（到 32°C 就开、低于 32°C 就停），温度在 32°C 上下抖一点，继电器就会"开—停—开—停"疯狂跳，几天就烧触点。
设 2°C 回差之后：到 32°C 才开，**要降到 30°C 才停**，中间不会来回。

> 这一段是「控制状态图」的核心，也是方案里唯一有点技术含量的设计决策。

## 6. 接线步骤（按顺序做，一步一验）

| 步 | 做什么 | 看到什么算成功 |
|---|---|---|
| 1 | 风扇装好，按原按钮 | **能正常转** ← 基线，已确认 |
| 2 | 断电 | — |
| 3 | 万用表核实基点：B+ 与 B− 之间、M+ 与 M− 之间 | B+/B− 读到 **3.5~3.9V**；M+/M− 不按键时接近 **0V** |
| 4 | 温控模块**先单独**接 B+/B−（这时先不碰电机线） | 数码管亮，显示当前温度 |
| 5 | 探头贴出风口，用手捂热 | 数码管数字明显上升 |
| 6 | 设置启动温度 32°C、回差 2°C | 屏幕显示设定值 |
| 7 | 万用表通断档量 COM–NO：温度低于阈值时 | **不通**（说明继电器没误吸合） |
| 8 | **把 M+ 端子上的电机线拆下来** | 电机线悬空，风扇彻底不动 |
| 9 | 这根拆下的电机线 → 接到继电器 **NO** | — |
| 10 | 再从 M+ 端子引一根线 → 继电器 **COM** | 继电器串进 M+ 通路 |
| 11 | 通电，按一下原按钮唤醒，但**先不加热** | 风扇**不转**（温度没到，说明串联生效） |
| 12 | 用手捂热探头，升到阈值以上 | **风扇自己转起来** ← 关键 |
| 13 | 松手，等温度降到「设定值 − 回差」以下 | **风扇自己停** ← 关键 |
| 14 | 再按原按钮 | 仍能手动开关，原逻辑没坏 |

第 11、12、13、14 四步就是「接线验证」的全部证据。
**特别注意第 11 步**：不加热时风扇不转，才证明"不是你在按按钮，是继电器在控制"。

## 7. 验证要拍什么（这段直接决定那 20 分）

原文写「动手完成接线验证**直接满分**」，所以要让人一眼看出「真的接上了、真的生效了」：

1. **改造前基线段**：按下按钮才转（5 秒）
2. **接线特写**：模块固定在哪儿、线怎么走、端子和继电器触点的近景
3. **唤醒段**：**按一下原按钮**——这一步要拍进去，不能省。方案本来就是"半自动"，如实拍才有说服力
4. **加热触发段**：手捂探头 → 数码管升温 → **风扇自己启动**（一镜到底，不要剪辑）
5. **降温停止段**：等温降 → 风扇自己停
6. **手动段**：再按原按钮 → 仍能手动开关
7. **完整电路全景**：能同时看到电池、原板、模块、电机

> 一镜到底比剪辑有说服力。中间断了、跳剪了，评审第一反应就是"是不是摆拍"。

## 8. 风险与备用方案

| 风险 | 判断 | 应对 |
|---|---|---|
| 买到的模块 3.7V 不启动 | 最常见 | 下单前问卖家；或改从 Type-C 取 5V |
| 端子认错（B+ 当成 M+） | **中等偏上** | 接前必须用万用表量电压核实，见第 4 节 |
| 继电器触点容量不够 | 可能性低 | 小风扇电机电流通常 < 1A，常见模块触点 10A，够 |
| 接反继电器 COM/NO | 低 | 接反不烧，只是通断逻辑相反，调换即可 |
| 模块待机耗电拖累续航 | 存在 | 记录改造前后「不插线能待多久」，写进方案的取舍说明 |
| 探头位置不当误触发 | 存在 | 探头贴出风口而非电机，避免电机自身发热干扰 |

**万一温控方案失败**：退回 `KSD9700` 机械温控开关（1~2 元，不需供电），接线更简单，同样能完成「接线验证」。
