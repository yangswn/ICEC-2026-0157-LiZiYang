## 三、从拆解里看出来的四件事

### 1. 电路拓扑（依据元件位置推断）

```
Type-C 5V ──→ [U3 充电管理] ──→ 电池 3.7V（2 节并联）
                                     │
                                     ↓
                        [U1 / U4 两颗 CSM4066T 并联]  ← 主回路开关
                                     │
              [U3 输出] ──→ [Q1 Si2302] ──→ 电机 M+/M−
                                              │
                              [D1 SS34] ←─────┘  续流
```

**这条链里有一点几乎是确定的**：D1 跨在电机两端、阴极朝 M+，是驱动**感性负载**的标准做法 ——
电机断电瞬间绕组会产生反向高压尖峰，D1 把它泄放掉，保护 Q1 不被击穿。

> 其余接线走向为**依据元件位置与功能需求的推断**，未逐脚测量验证，已在 BOM 备注里标明。

### 2. 同一块板两条装配路线（平台化设计）

- 正面留了 `B+ / B− / M+ / M−` 四个**焊接焊盘**，但本机型实际走的是背面的两个**白色连接座**；
- 另有 `Q4`、`R11` 两个**空贴位**（焊盘有残锡、元件未装）。

→ 说明这块 PCB 被**复用于多个型号**，按配置差异贴装与装配，用一次开模费摊薄多个 SKU 的成本。

### 3. 成本大头不在芯片上

按 1000 件批量估算（详见 `BOM成本核算表_v3.csv`）：

| 部分 | 金额 | 占比 |
|---|---|---|
| 整块电路板（正面 + 背面 + PCB 全含）| **4.51 元** | 33.3% |
| **电池 ×2 + 电机** | **5.80 元** | **42.9%** |
| 结构件（外壳/扇叶/导风圈/包装等）| 3.20 元 | 23.7% |
| **BOM 合计** | **13.51 元** | — |

**一块装了 4 个芯片、两颗 MOS、Type-C 和数码管的板子，还不如两节电池加一个电机值钱。**

### 4. 逆向卡在哪：最关键的那颗芯片没有丝印

这块板上唯一读不出型号的，恰好是最关键的 **U3（SOP-16）——出厂就是无字白片，表面能看到打磨痕迹**。

其余器件都保留着丝印：`CSM4066T`（MOS）、`A2SHB`（Q1）、`T4`（SS34），连 PCB 本身都印着 `Y30 / 20260202`。
**偏偏主控这一颗被处理掉了。**

**这里有两种可能，我分不开：**

| 可能 | 判断依据 |
|---|---|
| **A. 有意抹除**（防抄） | 表面有打磨/研磨痕迹，字体残留不均 |
| **B. 采购的就是无字裸片**（省钱） | 低端消费电子里很常见，未打标的散新片单价更低；表面可能平整或只有激光点 |

我倾向 A，但**没有证据排除 B**——两者在实物上的区别，需要放大看表面纹路才能分辨，我这次没做到。

**不管是哪一种，后果是一样的：**

这颗芯片决定了充电管理 + 电机控制的全部逻辑。没有型号，就没有 datasheet、没有引脚定义、也不能确定它内部到底集成了多少东西（是纯充电管理，还是充电 + MCU 二合一）。要往下走，只能靠**引脚功能反推 → 外围电路比对 → 上电试错**，而每猜错一次就是一轮返工。

**我的判断：逆向它的成本，已经超过了直接自己设计一块板的成本。**

自己设计的话，选一颗公开 datasheet 的成熟充电管理 IC（同类 SOP-8/SOP-16 方案市面资料齐全），画原理图、布板、打样，一次打样在百元级，工时是可控的。而逆向这颗白片，没有资料、不能确定功能边界，每一步都得靠测和试，**而且做到最后，得到的也只是一个"功能等价"的替代方案，不是原设计本身**。

所以这个项目对我的价值不在"把它抄回来"，而在于**看清这道墙有多高**：便宜的消费电子不用靠专利，靠"用一颗没字的定制 IC 把方案锁死"，本身就是一道极低成本的护城河。

## 四、已知问题与待办（我自己先写清）

1. **U3 是无字白片**，无法直接读出型号（详见第三节第 4 点）。计划用「引脚功能反推 + 外围电路比对」来判定功能，
   **不以"猜出型号"为目标**，而是把"为什么无法识别"和"能推断到什么程度"写清楚。
2. **位号存在记录冲突**：原记录写"实板丝印疑为 U4 / U5"，但背面又有一个 U2，需现场复核订正。
3. **BOM 部分单价为估算**（U3、CSM4066T、结构件等无公开批量报价可查），
   依据是同类器件市场区间，**非实际询价**，报告中已注明。
4. **拆解分步照片不完整**：本次先拆后补拍，缺逐步过程记录，计划以"爆炸图 + 装配顺序说明"补足。
5. **电机的有刷/无刷类型尚未确认**，直接影响升级方案能否用 PWM 直接调速。
