# Changelog

## 1.5.0 — 2026-11-13

**重构：把「先卸载再装」改成「覆盖安装」。**

### Changed

- 安装流程改为标准覆盖安装（与 Inno Setup / NSIS / MSI 升级一致）：版本检查 → 关闭安装目录内进程 → 备份关键数据 → 直接解压覆盖 → 写注册表并建快捷方式；
- **安装时不再调用旧版 `Uninstall.exe`**：旧卸载器不认识 `/KEEPDIR`，会整目录删除并排一个 `timeout 2 & rmdir /s /q` 的延迟删除，与新解压撞车——这正是 2026-11-13 数据被删事故的直接原因；
- 删除 `UninstallPrevious()`、`WaitForDirectoryRemoved()`、`Thread.Sleep(2500)` 及“删目录 + 轮询等待”整段逻辑；
- 消除“卸载完成到装好之间”的空窗：中途失败不再出现“软件没了”；
- `Uninstall.exe` 保留，用户主动卸载仍走它。

### Added

- 单文件覆盖的三层保护：
  1. 目标文件只读 → 先清 `ReadOnly` 属性再覆盖；
  2. 覆盖抛 `IOException`（句柄未释放）→ 等 300ms 重试，最多 5 次；
  3. 5 次仍失败 → **中止安装并报出具体文件路径**，不留下“装了一半”的状态。

### Verified

- 实测 1.4.3 → 1.5.0 覆盖安装（应用运行中）：自动关闭进程 → `upgrading from 1.4.3 to 1.5.0 by overwrite` → 备份 748 files / 98.5MB 校验一致 → 任务 34 项、通知 2 条、cookie、运行日志（11-09~11-13 共 5 天）全部保留，升级后免重新登录；
- 只读文件场景：把 `ClassBell.exe` 设为只读后安装，安装成功且属性恢复为 `Archive`，数据无损。
## 1.4.3 — 2026-11-13

升级时必须保住用户数据（任务 / 运行日志 / 登录 cookie）。

### Added

- 升级前同时备份**便携目录 `data\`**（含 `data.json`、`cx-cookies.json`、`process_logs`、`WebView2` 登录数据）与 `%APPDATA%\ClassBell` 的关键文件；
- 备份后**逐一校验**（文件数 + 字节数）。校验不一致直接抛异常**中止安装**，绝不“先删后装”；
- 备份目录保留不删，滚动保留最近 2 份，出问题可手工找回；
- 恢复时只补缺失的那一份，并保留 cookie 与日志。

### Verified

- 实测 1.4.2 → 1.4.3 覆盖安装：任务 34 项、通知 2 条、`cx-cookies.json`、`process_logs/2026-11-13.jsonl` 全部保留；升级后**免重新登录**（`loggedIn: true`）；
- 同级目录生成 `.classbell-data-backup-<时间戳>\`，内含 `install-data\` 与 `appdata\`。
## 1.4.2 — 2026-11-13

### Changed

## 1.4.1 — 2026-11-13

### Fixed

- **升级会删掉刚装好的文件（含用户数据）**：旧版卸载器不认识 `/KEEPDIR`，仍会安排 `timeout 2 & rmdir /s /q <安装目录>`；安装器解压后 2 秒，延迟删除把新文件连同 portable 的 `data\` 一起删了。现在改为：先备份 `<安装目录>\data` 到同级目录 → 跑卸载器 → 轮询到安装目录确实消失 → 再等 2.5 秒让延迟 rmdir 落空 → 解压 → 恢复 data；
- 便携数据备份从 `%TEMP%` 改到安装目录同级，避免受限环境下备份失败导致数据丢失。

## 1.4.0 — 2026-11-13

两个课铃实例互相打架导致启动失败（`E_ABORT` / `0x80040004`）。

### Added

- **单实例锁**：启动时先抢 `Local\ClassBell.SingleInstance` 命名互斥体（便携版与安装版共用同一锁名），抢不到就直接给人话提示并退出，不再初始化 WebView2；
- `--allow-multi` 逃生通道（调试两个版本时跳过检测）；
- 启动失败文案翻译：`E_ABORT`、缺 WebView2、无写入权限都翻译成“人话 + 下一步怎么办”，识别不了的保留原文并附日志目录；
- 安装前先卸旧版：读注册表/旧 exe 版本，旧版本更低时静默跑 `Uninstall.exe /S`，避免旧文件、快捷方式、注册表残留；
- 卸载器新增 `/KEEPDIR`（供安装器接管目录清理）。

### Verified

- `%APPDATA%\ClassBell` 与 `data\` 在升级中保留；卸载器静默模式默认保留数据；
- 单实例：两个不同目录的实例，第二个提示“课铃已经在运行”后退出，不再 `E_ABORT`。
## 1.3.9 — 2026-11-13

覆盖安装被旧进程占用导致升级失败（同学反馈：`runtime\node.exe` 正由另一进程使用）。

### Fixed

- 安装器在解压前先检测**本安装目录内**的 `ClassBell.exe` 与 `runtime\node.exe`；严格按可执行文件全路径匹配，**绝不按进程名批量杀 `node.exe`**（避免误杀用户其它 Node 程序）；
- 检测到运行中时弹「课铃正在运行（共 N 个进程）」说明框，提供「自动关闭并继续安装」/「取消」，不再直接报文件占用错误；
- 自动关闭顺序固定为**先 ClassBell.exe、后 runtime\node.exe**：反过来主程序会把 node 重启，等于没关；先 `CloseMainWindow()`，2 秒不退再 `Kill()`；
- 关不掉时给出人工退出指引（托盘 → 退出课铃 / 任务管理器结束 ClassBell.exe）并允许「重试」；
- GUI 安装器支持 `--dir=<路径>` 预填安装目录（覆盖安装与自动化验收都用到）。

## 1.2.5 — 2026-11-11

### Fixed

- **字号引导每次启动都弹**：本地服务每次启动监听随机端口，页面源（含端口）一变，`localStorage` 就等于换了一个存储空间，`scaleGuideDone` / `uiScale` / `lastPage` 全部读不回来。现在这些界面偏好改存到服务端 `settings`（端口无关），`localStorage` 仅作兼容缓存；
- 顺带修复“上次停留的页面”重启后丢失（同一根因）；
- 日志结果列改为三态「正常 / 已恢复 / 异常」，403 这类由备用通道兜底的事件不再显示成红色异常，也不再计入错误数（含历史日志）。

> 版本规则（语义化版本）：`主.次.补丁`。
> - 功能、安全或行为变更 → **次版本 +1**（例如 1.0.9 → 1.1.0）；
> - 只修缺陷 → **补丁 +1**（例如 1.1.0 → 1.1.1）；
> - 不再使用 `1.0.10` 这种两位补丁号。
> `package.json` 的 `version` 是唯一版本源，构建脚本会自动同步程序集版本、安装器版本、安装包文件名与界面版本号。

## 1.1.3 — 2026-11-10

### Fixed

- **导出日志/导出数据点了没反应**：原来用网页里的 `<a download>` 触发下载，WebView2 在部分机器上会静默拦截，既不落盘也不报错。现在改为宿主接管：从本地服务取内容 → 弹“另存为” → 用 UTF-8（无 BOM）写盘，并提示实际保存路径；
