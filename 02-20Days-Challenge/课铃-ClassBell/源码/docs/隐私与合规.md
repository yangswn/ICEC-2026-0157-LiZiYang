# 隐私与合规说明

## 数据最小化

课铃只处理完成提醒所必需的数据：

- 任务标题、课程、类型、截止时间、备注（用户自己填写或从学习通可见页面读取）；
- 本地设置；
- 运行事件（事件名、耗时、错误码、非敏感计数）；
- 登录 Cookie（由 WebView2 管理，用于请求学习通接口）。

以下内容**不会**写入日志：

- 账号、密码、验证码；
- Cookie / Token；
- 课程标题、作业正文、备注；
- 完整 URL、查询参数。

## 本地优先

- 任务与设置：`%APPDATA%\ClassBell\data.json`；
- WebView2 登录数据：`%APPDATA%\ClassBell\WebView2\`；
- 日志：`%APPDATA%\ClassBell\process_logs\`；
- 可选 Git 镜像：由用户手动选择仓库目录，程序只写 `<仓库>\process_logs\`。

本地服务只绑定 `127.0.0.1`，不监听局域网地址，不向云端上传数据。

## 学习通使用边界

- 课铃不是学习通官方产品，与超星/学习通无隶属关系。
- 仅读取当前登录用户本人有权访问的课程、作业、考试信息。
- 不提供代刷、自动提交作业、自动考试、绕过验证码等功能。
- 登录由用户在官方页面完成；程序不代填、不存储密码。
- 学习通平台规则、接口或页面结构变化可能导致同步失败；用户应遵守学校与平台规定。

## 日志与 Git

- 日志默认只在本机。
- “设为 Git 仓库”是显式操作；程序只写日志，不读取仓库其他文件，不自动 push。
- 用户提交到公开仓库前，应确认日志中没有自己额外写入的敏感信息；课铃自身不会写。
- 卸载时可选择删除 `%APPDATA%\ClassBell`；日志也会一并删除。
