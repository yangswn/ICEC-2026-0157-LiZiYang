# 课铃使用手册

## 1. 安装与启动

1. 双击 `ClassBell-Setup-1.11.3.exe`。
2. 勾选“我已阅读并同意 MIT 许可协议与隐私说明”，点击“开始安装”。
3. 可修改安装位置；默认是 `%LOCALAPPDATA%\Programs\ClassBell`，不需要管理员权限。
4. 安装完成后勾选“立即启动课铃”，或双击桌面快捷方式。

Windows SmartScreen 如提示未知发布者，这是未签名应用的正常提示；选择“更多信息 → 仍要运行”。

## 2. 第一次使用

主窗口左侧有七个页面：

- **今日概览**：下一次截止倒计时、今日/本周统计、最近任务。
- **任务日程**：搜索、筛选、完成、编辑、删除任务。
- **学习通同步**：登录学习通并同步作业/考试。
- **通知中心**：提取学习通通知与本地关键事件，集中查看与标记已读；
- **器材借还**：登记借出、核对归回、提示逾期；
- **错题本**：按课程归档错题，支持自动读取与手动补录；
- **偏好设置**：提醒、后台运行、字号（三处各自一档）、桌面浮窗（条数 + 透明度）、运行日志、数据备份与退出。

第一次打开会看到欢迎卡：

- “连接学习通”：进入同步页并打开登录窗口；
- “先手动添加”：直接创建第一条日程。

## 2.1 升级装到哪个目录

课铃会装回**上次装的那个目录**（读注册表的 `InstallLocation`），不会因为换了默认值就另建一份。
装完会顺手把桌面和开始菜单的快捷方式指回当前目录，并回读确认 ——
如果机器上还有另一份课铃，完成页会提示路径和版本（只提示，不自动删）。

## 2.1 覆盖安装（升级）

课铃默认留在托盘运行。直接双击新安装包时，安装器会先检测旧进程：

1. 弹出「课铃正在运行」，显示检测到的进程数量；
2. 点「自动关闭并继续安装」会按 **先主程序、后 runtime\node.exe** 的顺序关闭，然后继续安装；
3. 若自动关闭失败，按提示从托盘退出（或任务管理器结束 ClassBell.exe）后点「重试」。

安装过程只会关闭**本安装目录**里的进程，不会碰你机器上其它 Node 程序。

**覆盖安装不会先卸载**：新版安装器直接覆盖旧文件（与主流安装器一致），不会再调用卸载程序、
也不会删除安装目录，因此不存在“卸载完成后装不上”的空窗。

**升级不会丢日志和登录**：安装器会先把 `data\`（任务、运行日志、`cx-cookies.json`、WebView2 登录数据）
备份到安装目录同级的 `.classbell-data-backup-<时间戳>\`，校验通过才继续；装完再补回缺失的文件。
备份会保留最近 2 份，出问题可以手工恢复。

### 只能同时运行一个课铃

课铃的内嵌浏览器（WebView2）同一时间只能被一个课铃使用。**便携版和安装版也一样**。

如果你已经开着一个课铃，又双击另一个（例如换了目录的便携版），会出现：

> 课铃已经在运行了（图标可能在右下角 ^ 里）。

这是正常的保护行为，不是报错。要从托盘打开；或先退出正在运行的那个课铃。

### 托盘菜单

- 右键托盘图标 → 立刻弹出菜单，最后一项是「退出课铃」；
- 左键单击 / 双击 → 打开主窗口（不会因为右键而误开窗口）。

## 3. 学习通登录

1. 左侧进入“学习通同步”，点击“打开学习通登录窗口”。
2. 在弹出的独立窗口扫码，或使用手机号/超星号 + 密码登录。
3. 登录成功时顶部会显示“已登录，正在同步作业…”。
4. 关闭登录窗口，回到同步页点击“同步作业与考试”。

说明：

- 密码只输入到学习通自己的页面，课铃不读取、不保存。
- Cookie 保存在本机 WebView2 用户数据目录。
- 如果登录页打不开，检查网络；学习通部分页面需要校园网/VPN。
- 如果同步失败，错误会写入运行日志（不含个人信息），可稍后重试。

## 4. 同步结果

同步会尝试读取：

- 作业列表与截止时间；
- 考试列表与截止时间；
- 课程列表（用于显示课程数）；
- 当前登录用户可见的任务。

结果分两类：

1. **有截止时间**：自动加入任务日程，并按默认提醒规则生成提醒。
2. **缺截止时间**：进入“待确认”。点击“设为日程”，补全截止时间后保存。

已提交/已完成的远端任务不会重复加入；本地完成后，下次同步会保留完成状态。

## 5. 手动新建日程

点击右上角“新建日程”或按 `Ctrl+N`：

- 标题（必填）；
- 课程；
- 截止时间（必填）；
- 类型：作业/考试/日程/其他；
- 优先级：普通/重要/紧急；
- 提醒：提前 1 天/1 小时/10 分钟/准时，可多选；
- 重复：不重复/每天/每周/每月；
- 备注。

每月重复的日期规则：以首次设置的“日”为锚点。例如 1 月 31 日 → 2 月 28 日（当月没有 31 日）→ 3 月 31 日，不会永久变成 28 日。

**改到更早的月份也不会错位**：把每月重复的截止日从 11 月改到 9 月，下一期是 **10 月**；
改期相当于「从这一期重新按月往后排」，起始月会跟着新日期走（之前会算成 12 月）。

**重复任务的下一期是干净的**：完成一期时，新一期不会继承上一期的「已开始做」和实际耗时，
也不会沿用上一期的估时 —— 它是一张新的、待办状态的任务。

补完一条已经过期的重复任务时，下一期会自动滚到“今天之后”的下一个周期，不会立刻又出现一条逾期任务。

任务列表默认按截止时间升序；已逾期任务单独分组并标红。完成后会进入“已完成”，可恢复。

### 今晚能做多少（估时）

首页有一块「今晚能做多少」：先点你还有多久（1 小时 / 2 小时 / 3 小时 / 半天），
课铃会按截止紧迫度排出**这时间内能做完的几条**，并显示每条大概要多久、合计多久。

时长怎么来的（按可信度从高到低）：

1. **你以前做过同类任务**（同一门课、题量相近，且至少做过 3 次）→ 取实际耗时的中位数；
2. **本机装了 Ollama** → 让它估（分批问，最多 30 秒，超时就退回第 3 级）；
3. **题量** → 每题 1.5 分钟，最少 15 分钟；
4. **标题关键词** → 含「报告」60 分钟、含「测试」30 分钟、含「工作页/作业」15 分钟；都没有就给 30 分钟平均值。

打开开关后，开关下方会显示一行状态：装好模型是「✓ 已就绪（qwen2.5:1.5b）」，
没装是「⚠ 未检测到 qwen2.5:1.5b · 复制安装命令」—— 点「复制安装命令」把命令复制到剪贴板，
粘到终端里执行即可。**没装模型时点「今晚能做多少」不会弹任何错误**，照常用按题量算的结果。

**模型估时是可选的**：默认只按题量算（毫秒级）。设置页可以打开「用本机模型精估耗时」，
但需要本机装好 Ollama 和 `qwen2.5:1.5b`（约 1GB，5GB 以上内存）。没装会提示你去 pull，
课铃不会自己换成更大的模型 —— 那会把电脑拖卡。

想让估时越来越准：点任务上的「开始做」，做完再点完成，课铃会把这次的实际耗时记下来。
没点「开始做」直接完成的话，会问一次「这条大概花了多久？」——只问一次，之后不再追问，也不会自己瞎猜。

估时只是参考，文案统一写「大概」。排序永远按截止时间算，模型不参与排序。

### 桌面浮窗

默认开启。桌面上会常驻一小块，显示接下来要做的任务和倒计时，不用打开主窗口也能看见。

- **显示 1–3 条**：在「设置 → 字号」下面那一块里调；条数越多窗口越高，1 条时的样子和以前一致；
- **按优先级排**：紧急 > 重要 > 普通；同优先级按截止时间从早到晚。紧急题目标题是红色、重要是金色；
- **同系列合并成一格**：每天的重复任务只占一行，右上角小字写「下次 明天 12:40」，把位置让给别的任务；
- **透明度 30%–100%**：滑杆连续可调，拖动时浮窗实时跟着变，松手才保存；
- **悬停变清晰**：鼠标移上去完全不透明，移开回到你设的透明度；

- **拖动**：按住任意位置拖，松手后位置会记住，下次启动还在原处；
- **双击**：打开主窗口；**右键**：打开课铃 / 设置 / 隐藏浮窗；
- **不抢焦点**：浮窗出现和刷新时不会把你正在打字的窗口顶掉；
- **全屏自动让路**：看视频、打游戏、全屏放 PPT 时自动隐藏，退出全屏自动回来；
- 待办清空后显示「今天没有待办」，3 秒后淡出；
- 换显示器或拔掉副屏后，位置会自动回到主屏右下角。

**找不到浮窗了？** 三个入口都能找回来：

1. 右键托盘图标 → 勾选「桌面浮窗」（最快，勾上立刻出现）；
2. 设置页打开「桌面浮窗」开关（立刻生效，回到上次位置）；
3. 右键浮窗本身只会「隐藏」，要找回来用上面两个。

在浮窗上点「隐藏浮窗」= 这次先不看，重启课铃后会恢复显示；
在设置页/托盘取消勾选 = 关掉这个功能，重启也不显示。

不想看它：设置页关掉「桌面浮窗」即可，重开后会回到上次的位置。

## 6. 提醒

提醒弹窗默认在屏幕右下角置顶：

- **标记完成**：完成当前任务；
- **稍后 10 分钟**：延迟提醒；
- **查看任务**：打开主窗口并定位到任务；
- **× / Esc**：关闭本次提醒。

设置中可以：

- 修改新任务默认提前提醒；
- 关闭提醒声音；
- 设置静音时段（弹窗仍显示，只是不响）；
- 测试弹窗。

## 7. 托盘与开机自启

关闭主窗口时默认隐藏到系统托盘，程序继续运行并按时提醒。

**第一次点窗口右上角的 ×**，会弹出一个说明框：

- 「知道了，继续用」→ 窗口收进托盘，提醒照常；
- 「立即退出」→ 课铃和后台服务一起关闭，不再提醒。

这个说明只弹一次。想改这个行为：偏好设置 → 运行与同步 →「关闭窗口时最小化到托盘」；
关掉后点 × 会直接退出课铃（不再提醒）。

找回窗口：按 `Ctrl+Alt+B`，或双击桌面“显示课铃”。

> Win11 默认会把新程序的托盘图标折叠进右下角的 **^** 溢出区，看不到不等于没运行。
> 每次收进托盘后右下角会出现一个几秒的提示窗，告诉你程序还在跑、图标在哪里、怎么找回。

偏好设置中还有：

- **字号**：三处各自一档 —— 主界面 / 桌面浮窗 / 提醒弹窗，都是小 / 标准 / 大 / 特大 / 超大 / 巨大；主界面也能用 `Ctrl` + `+`、`Ctrl` + `-`、`Ctrl` + `0`；
- **桌面浮窗内容**：显示条数（1 / 2 / 3）与透明度（30%–100% 连续滑杆）；
- **终止课铃**：左侧底部的红色按钮，确认后关闭程序和后台服务。

托盘菜单：

- 打开课铃；
- **桌面浮窗**（勾选项：勾上立刻出现，取消立刻隐藏）；
- 手动添加日程；
- 立即同步学习通；
- 开机自动启动；
- 退出课铃。

要彻底退出，请使用托盘菜单“退出课铃”，而不是只在任务管理器结束进程。

## 8. 通知中心

进入“通知中心”：

- **从学习通提取**：尝试读取学习通通知页，同时把本地的逾期作业、已错过作业、逾期未还器材整理成通知；
- **手动添加**：填写标题、课程、类型和正文；
- 点标题可展开正文；未读左侧有红点，可逐条标为已读，或“全部已读”。

学习通通知接口没有公开稳定地址，若提取不到线上通知，本地关键事件仍会照常生成。

## 9. 器材借还核对

进入“器材借还”，点“登记借出”填写：

- 器材名称、编号；
- 借用人；
- 借出时间、应还时间；
- 备注（配件、存放位置等）。

列表按“逾期未还 → 借出中 → 已归还”排序。点“归还”即核对完成，记录保留但不再提醒。
“核对未还”会汇总当前未还数量与逾期数量。逾期器材会出现在通知中心。

## 10. 错题本

进入“错题本”：

- **扫描当前作业页**：在登录窗口打开“已批改”的作业详情页，回到错题本点一下，直接读取当前页面文字并归档；
- **从学习通归档**：批量读取作业详情页，跟进 `doHomeWork` 跳转，按“我的答案 / 正确答案 / 解析”识别错题；
- **手动添加**：填写课程、来源作业、题目、我的答案、正确答案、解析和考点标签；
- 顶部可按课程筛选，卡片上会标注“自动归档 / 手动记录”。

自动识别依赖学习通作业详情页的结构；如果页面是图片题、验证页或结构变化，识别不到时请手动添加。

## 11. 数据备份

“偏好设置 → 数据与日志”：

- **导出数据**：生成 JSON 备份（任务与设置，不含 Cookie/密码）。
- **导入数据**：合并导入任务，重名 ID 会自动换新。
- **打开数据目录**：查看 `data.json`、`server.log`。
- **选择 Git 仓库**：把日志按天镜像到 `<仓库>\process_logs\`。

导出的文件会保存到哪里：点“导出全部日志”/“导出数据”会弹出 Windows 的“另存为”对话框，默认文件名带日期时间，保存成功后会提示完整路径。若在浏览器兜底模式下使用，则走浏览器自己的下载。

## 12. 日志

偏好设置最下方的运行日志区展示：

- 连续运行天数；
- 今日事件数；
- 7 日错误数；
- 7 日同步次数；
- 近 7 天事件柱状图；
- 本机日志路径与 Git 镜像路径；
- 最近事件表（时间、事件、结果、耗时、备注）。

日志不记录账号、密码、Cookie、课程标题、作业正文或完整 URL。可直接“打开日志目录”查看 JSONL，或“导出全部日志”。

## 13. 常见问题

**Q：登录成功但没有作业？**  
A：可能接口暂时被验证页拦截，或课程作业确实没有截止时间。先打开一次课程作业页，等几分钟再同步；缺截止时间的条目会进入“待确认”。

**Q：关闭窗口后还会提醒吗？**  
A：会，默认隐藏到托盘。用 `Ctrl+Alt+B` 或桌面“显示课铃”找回，且没有在设置中关闭“关闭窗口时隐藏到托盘”。

**Q：重装后数据还在吗？**  
A：默认数据在 `%APPDATA%\ClassBell`，覆盖安装不会删除。卸载时会询问是否保留。

**Q：提示无法写入 AppData？**  
A：受限账户/公共电脑可能禁止 `%APPDATA%`。课铃会自动回退到安装目录的 `data\`。可在“偏好设置”中查看实际数据目录。

**Q：安装包提示未知发布者？**  
A：当前版本未做商业代码签名，SmartScreen 会提示；不影响安装与使用。
