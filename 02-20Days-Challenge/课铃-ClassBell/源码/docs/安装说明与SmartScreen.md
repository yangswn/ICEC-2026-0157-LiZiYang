# 安装说明与 SmartScreen 提示

## 为什么会出现“Windows 已保护你的电脑”

这是 Microsoft Defender SmartScreen 的提示，不是安装包损坏。

课铃当前版本**没有购买商业代码签名证书**。Windows 对“没有数字签名、下载量少、没有信誉记录”的新程序会默认拦截，显示：

> Windows 已保护你的电脑  
> Microsoft Defender SmartScreen 阻止了无法识别的应用启动。

这不等于检测到病毒，但 Windows 无法确认发布者身份，所以要求你手动确认。

## 解决办法（推荐顺序）

### 方法 1：仍要运行

1. 点击提示框左侧的 **“更多信息”**；
2. 底部会出现 **“仍要运行”** 按钮；
3. 点击“仍要运行”即可继续安装。

不要点“不运行”。

### 方法 2：先解除文件锁定

如果右键属性里显示“此文件来自其他计算机，可能被阻止”：

1. 右键安装包 → **属性**；
2. **常规** 页底部勾选 **“解除锁定 / Unblock”**；
3. 点击 **应用 → 确定**；
4. 再双击安装。

PowerShell 也可以：

```powershell
Unblock-File -Path .\ClassBell-Setup-1.0.0.exe
```

### 方法 3：校验文件hash

如果担心文件被替换，先核对 SHA-256：

```text
F6C94C5C05D774EAA2FE6499B0BEA1B86E6E237E55E4838EC4FDD32A91940B35
```

PowerShell：

```powershell
Get-FileHash .\ClassBell-Setup-1.0.0.exe -Algorithm SHA256
```

哈希一致说明文件没有被改动。

### 方法 4：被杀毒软件隔离时

如果文件被 Windows Defender 直接隔离：

1. Windows 安全中心 → 病毒和威胁防护 → 保护历史记录；
2. 找到对应记录 → **还原**；
3. 如确认来源可信，再添加排除项。

只对你自己确认过哈希的文件这样做，不要对来源不明的文件关闭防护。

## 不建议的做法

- 不建议全局关闭 SmartScreen 或杀毒软件；
- 不建议为了“看起来不报错”而使用来源不明的“签名工具”；
- 不建议把安装包重新打包成自解压 EXE，SmartScreen 仍可能拦截。

## 想彻底消除提示

需要给安装包购买 **代码签名证书** 并签名：

- OV 证书：较便宜，但新证书仍需要积累下载信誉；
- EV 证书：审核更严格，SmartScreen 信誉建立更快；
- 个人/学生项目通常不购买，保留“更多信息 → 仍要运行”的说明即可。

## 给同学/老师的分发建议

1. 连同本说明一起发送安装包；
2. 附上 SHA-256；
3. 说明这是未签名的学生项目，安装时需点“更多信息 → 仍要运行”；
4. 不要通过未知网盘二次转发，避免文件被替换。
