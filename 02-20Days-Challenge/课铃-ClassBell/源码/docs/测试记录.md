## 3. 已知限制

- 学习通接口可能返回验证页（WAF），此时作业接口会失败；H5 列表与手动记录仍可用。
- 未登录状态只能手动记录，这是设计边界。
- 提醒依赖课铃进程运行；退出程序后不会提醒。默认开启托盘与开机自启。
- 安装包未签名，SmartScreen 可能提示未知发布者。
- 7 天连续日志需真实使用自然累积，当前第 1 天。

## 4. 失败与修复记录（用于 Git 迭代）

1. 提醒窗口初始使用独立 WebView2 用户数据目录，导致第二个 WebView2 无法初始化（空白弹窗）。修复：共享主窗口的 `CoreWebView2Environment`。
2. 提醒文案把 `late_min`（提醒延迟）当成截止状态，出现“截止时间已过 / 剩余 1 分钟”矛盾。修复：按 `dueAt - now` 判断。
3. 任务列表过期标签拼接了“逾期 1 天 23:59”。修复：逾期只显示相对天数，具体截止时间放入副标题。
4. 正常退出时后端被强制结束，缺少 `app_stop`。修复：新增 `/api/shutdown`，宿主等待退出并写索引。
5. 受限账户无法写 `%APPDATA%` 时启动失败。修复：写入探针失败则回退到安装目录 `data\`。
