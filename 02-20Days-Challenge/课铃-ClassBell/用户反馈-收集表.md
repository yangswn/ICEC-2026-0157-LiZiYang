## 一、什么叫"能算数"的反馈

不用很正式，但**必须能被追问**：

| 要素 | 说明 |
|---|---|
| **是谁** | 真实的人（同学/室友/朋友），能说出名字或昵称 |
| **什么时候** | 使用日期 |
| **用来干什么** | 装在自己电脑上、用自己的学习通登录、真的用它看作业 |
| **说了一句什么** | 喜欢什么 / 缺什么 / 哪里看不懂 |
| **有痕迹** | 聊天记录截图、软件界面截图、或问卷截图 |

**四样缺一样都容易被质疑。** 尤其"有没有真的装、真的用"，是这个项目能不能站住的关键。

## 二、隐私前提（必须先跟对方说清）

课铃的做法是**本机保存登录 Cookie**，不上传服务器。发给同学时，先把这句一起发过去：

> 这个是本机的作业提醒小工具，登录信息只存在你自己电脑上，不会传到任何服务器；不想要了直接卸载就行，不留东西。

**这句话必须说，不然没人愿意拿自己的学习通账号试。**

## 三、发给同学的话术（可直接复制）

> 我做了个小工具，装在电脑上，能把你学习通里没交的作业拎出来提醒，还能设提前一天提醒。
> 安装包 30 多 M，装完用自己的学习通登一次就行，登录信息只存本地。
> **⚠️ 装的时候 Windows 可能弹一个蓝色的「Windows 已保护你的电脑 / 未知发布者」——
> 那是因为我没买代码签名证书（要几千块），不是病毒。
> 点左边「更多信息」→ 下面出现「仍要运行」→ 点它就能装。**
> **⚠️ 如果打开后提示「Couldn't find a compatible WebView2 Runtime」，是系统缺了微软的
> WebView2 运行库（和你电脑上装没装 Edge 无关）。装一下这个就好：
> https://developer.microsoft.com/microsoft-edge/webview2/
> 选「Evergreen Bootstrapper」下载，双击，几秒钟装完，不用重启。**
> 帮我试用两三天，然后随便说一句"好用/不好用、缺什么"就行，我要写进课程作业里的用户反馈，谢谢！

**不要一次群发 8 个人**——先找 2 个愿意的，用顺了再找剩下 6 个。前面两个会暴露问题，改完再发下一批。

> 📌 **两段警告都要带上。** 少了它们，8 个人里很容易有几个卡在提示框前直接放弃，
> 而你以为他们是"不想用"，实际是"装不上"。
> SmartScreen 见 `campus-pulse/docs/安装说明与SmartScreen.md`；WebView2 见下面第五条。

## 四、已知安装阻塞（2026-11-10 由第 1 位试用同学暴露）

### ① 缺 WebView2 Runtime（最高频）

**现象**：双击后弹「课铃启动失败：Couldn't find a compatible WebView2 Runtime installation to host WebViews」

**原因**：课铃的界面用的是 **WebView2**（微软的嵌入式浏览器组件）。Win11 一般自带，**Win10 或精简系统可能没有**。这跟"装没装 Edge 浏览器"不是一回事。

**解决**：

| 情况 | 做法 |
|---|---|
| 正常系统、确实没装 | 装 Evergreen Bootstrapper：`https://developer.microsoft.com/microsoft-edge/webview2/` → 双击 → 几秒完成，**不用重启** |
| 装完还报错 | 可能装的是 32 位包或版本过老，换成 x64 Standalone Installer 重装 |
| **路径里出现 `C:\Users\WDAGUtilityAccount\`** | ⚠️ **这台机器在 Windows 沙盒（Sandbox）里跑**，沙盒是干净镜像、通常不带 WebView2，**而且关机就清空**。→ **让他在正常桌面直接运行，不要在沙盒里测** |

**自查有没有装**：`Win + R` 输入 `appwiz.cpl`，在程序列表里搜 `WebView2`。

**产品级解法（第 9 次迭代候选）**：安装器启动时读注册表
`HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}` 的 `pv` 值，
缺失或 `0.0.0.0` 就弹一句人话提示 + 一键下载，而不是抛出一句英文异常。

### ② SmartScreen「未知发布者」

见 `campus-pulse/docs/安装说明与SmartScreen.md`。点「更多信息 → 仍要运行」。

## 六、反馈怎么变成"迭代依据"（这一步才算加分）

收集完之后，做一次归类：

| 反馈类型 | 举例 | 处理 |
|---|---|---|
| **功能缺失** | "想看今天有几门课" | → 记录为待办，能做的做进第 4 次迭代 |
| **打扰过多** | "一天弹好几次" | → 调整提醒频率 |
| **看不懂** | "不知道那个'长期任务'是什么" | → 改文案 |
| **登录顾虑** | "不敢登自己的号" | → 补隐私说明 |

**然后至少在文档里写一句**：*"第 N 位用户反馈 X，我在第 4 次迭代改成 Y。"*
**这句话把"用户反馈"和"迭代记录"接上了，是这一项最值钱的地方。**
