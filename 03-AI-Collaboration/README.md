## 从这里能看出的一条线

```
10-12  先要报错原文，别凭"常见原因"猜
10-13  别把推断当事实，要标来源          ← 规矩成型
11-05  别把"做了动作"当成"结果对了"
11-12  别信"已完成"的汇报，去数
11-19  别先改数字，先查单位
11-19  别信"我改了"，要看装上去的是哪份
11-22  别在旧数上加减，重算
11-24  别默认文件里的东西是对的，验
```

**核心就一句：AI 说"好了"，我要自己看一眼。**
