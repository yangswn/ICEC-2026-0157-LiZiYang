第一阶段我选了**课题 03** 和**课题 06**：

| 编号 | 课题名称 | 采样要求 |
|---|---|---|

| **课题 06** | 校园昼夜声学噪声地图测绘 | 5 个点位（图书馆、食堂、主干道、运动场、实训室走廊），测早/午/晚的噪声均值与峰值 → **15 组数据** |

1. **执行方式一致。** 两个都是"点位型"课题 —— 到点、测量、记录、拍同框照。用同一套流程能做完两个课题，不用来回切换思路。
2. **点位都在我自己的活动范围内。** 不依赖其他学院的场地（我的教室在 378，属于中德智造学院）。
3. **两个课题刚好互补。** 课题 03 测的是**看不见的电磁环境**，反映的是**空间上的衰减**；课题 06 测的是**听得见的声音环境**，反映的是**时间上的波动**。合起来正好构成"校园物理环境"的两个切面。

**预期产出：**

- 一张校园无线信号强度分布图，标出盲区位置

## 五、踩坑与经验

（这里记录你遇到过的报错和解决办法 —— 这部分对 `03-AI-Collaboration/` 很有用）

- **现象**：在 Git Bash 里敲 `git --version` 报 `command not found`
  **原因**：粘贴时带进了隐藏的转义字符（`^[[200~`），或者漏打了 `git` 和 `--version` 中间的空格
  **解决**：短命令直接手打，不要粘贴

- **现象**：`git push` 显示成功（`main -> main`），但**两个 CSV 数据表根本没上传**
  **原因**：`.gitignore` 里有一条目录级排除规则 `01-Field-Discovery/raw_data/*`，
  把必交的原始数据表**静默屏蔽**了。`git add .` 对忽略的文件不报错、不提示。
  **排查**：数 `git commit` 输出里的 `files changed` 数量 —— 说好 4 个只进了 2 个
  **解决**：删掉目录级排除规则。排除大文件要按**扩展名**写（`*.mp4`），
  不要按**目录**写（`raw_data/*`）。改完用 `git add -A --dry-run` 实测验证。
  **教训**：ignore 规则会**静默失败**，必须验证，不能想当然。
